# imysia-site

Source du site vitrine d'Imysia — https://imysia.fr

Hébergement : OVHcloud, offre Free 100M liée au domaine imysia.fr, datacentre de Gravelines (France).
Ce dépôt n'est plus publié par GitHub Pages : il sert uniquement de source.

Mise en ligne : déposer le contenu du dépôt (hors README.md) dans le dossier `www` de l'hébergement, en SFTP
(`sftp://ftp.cluster129.hosting.ovh.net`, port 22).

Polices auto-hébergées dans `fonts/` (licence SIL OFL), aucune ressource tierce chargée.
