# Logo Imysia

- `imysia-logo.svg` / `imysia-logo-blanc.svg` : icône Module + nom, pour fond clair / fond sombre (usage principal).
- `imysia-wordmark.svg` / `imysia-wordmark-blanc.svg` : le nom seul. Les points des deux « i » sont des carrés bleus.
- `imysia-icone.svg` / `imysia-icone-blanc.svg` / `imysia-icone-512.png` : l'icône seule (grille 3×3, module central bleu).

Couleurs : encre #1a1a1a, bleu Imysia #3e5a78 ; sur fond sombre : #f0f0f0 et #9fb6cf.
Nom dessiné à partir de la police Almarai Light (SIL OFL), vectorisé.
Zone de protection : la largeur d'un module de la grille tout autour. Taille minimale : 16 px pour l'icône, 80 px de large pour le logo complet.
